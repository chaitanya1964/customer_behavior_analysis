
Customer Behavior Analysis is a data analytics project focused on understanding customer purchasing patterns and generating actionable business insights from customer transaction data.

The project follows an end-to-end data analytics workflow, starting with data loading and exploration in Python, followed by data cleaning and preparation, SQL-based analysis using PostgreSQL, and finally the creation of an interactive Power BI dashboard.

The analysis explores customer demographics, purchasing behavior, spending patterns, product preferences, and other key business metrics. Python was used for Exploratory Data Analysis (EDA) and data preprocessing, while SQL was used to answer business-related questions and extract meaningful insights from the database. The processed results were then visualized in Power BI through an interactive dashboard.

The project demonstrates practical skills in Python, Pandas, Data Cleaning, EDA, SQL, PostgreSQL, Data Visualization, Power BI, and Business Intelligence, while showcasing the complete process of transforming raw data into meaningful business insights.
